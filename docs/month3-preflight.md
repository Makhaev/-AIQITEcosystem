# Проверка зависимостей перед разработкой месяца 3

Дата: 22 октября 2026 года. Перед началом изучены исходники, миграции 001–017, OpenAPI, сохранённые результаты M2 и выполнены 11 интеграционных проверок. Первичный результат сохранён в [отчёте preflight](reports/month3-preflight-2026-10-22.json): это исторический снимок до доработки.

Обнаруженные пробелы были перечислены пользователю. Последующие указания «доработай эту задачу» приняты как разрешение продолжить предложенные доработки. Ниже — состояние после работы; сведения о ранее отсутствовавших функциях не выдаются за первоначально готовые зависимости.

| Зависимость | Сейчас | Доказательство |
| --- | --- | --- |
| Авторизация, сессии, серверные права | Есть | Модуль `auth`, повторная авторизация внутри `access.Begin`, сессия/блокировка/роли, CSRF, объектные политики |
| Ученики, родители, семейные связи | Есть | Миграция 003, модули `students/parents`, сохранена ограниченная проекция чистого педагога |
| Расписание и посещаемость | Есть | Модули `lessons/attendance`, состав, журнал, перенос, завершение, история |
| Задания, попытки, проверка | Добавлен действующий базовый срез | Миграция 020 и модуль `learning`: назначения опубликованного шаблона, форматы text/link/file, неизменяемые попытки, решения, актуальность оснований |
| Программы | Есть | Версии, публикация, сохранённые шаблоны `curriculum`, миграция 017 |
| Прогресс программы | Добавлен | Миграция 019, отчёты занятий, обязательные элементы с явными весами, пересчёт после отзыва; нет плана — null |
| Цели, работы, достижения | Добавлен действующий базовый срез | Миграция 020: цели текущего куратора, точные основания, индивидуальные проектные вклады, подтверждённые достижения |
| Наблюдения и навыки | Добавлены наблюдения и хронология | Факт/трактовка, проверка, публикация, редакции; без автоматического уровня и без имитации утверждённой модели |
| Приватные файлы | Добавлены | Миграция 018, реальные байты в PostgreSQL, отдельные разрешения, отзыв и авторизованное скачивание |
| Audit Log | Есть и расширен | Неизменяемый журнал, атомарные события новых модулей; интеграция проверяет откат при ошибке аудита |

Полные процессы M3 01–03 остаются шире реализованного среза. Подробные ограничения, действующая политика доступа, новые маршруты и результаты проверок находятся в [отчёте реализации](month3-student360-report.md). Отсутствующие расширенные функции не представлены фиктивными успешными ответами API.
