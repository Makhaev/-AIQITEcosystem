# Тесты как домашние задания

В кабинетах методиста и куратора доступен раздел «Тесты и ДЗ». Автор создаёт тест из 1–30 вопросов, указывает 2–6 вариантов и один правильный ответ для каждого вопроса, выбирает до 100 учеников и при необходимости срок по Москве. После выдачи содержание теста сохраняется без изменений.

Методист может выбрать любого активного ученика, куратор — активных учеников закреплённых групп. Авторы видят результаты своих тестов: ученика, число попыток, количество правильных ответов и дату выполнения. Администратор и руководитель могут просматривать все выданные тесты.

Ученику тест доступен в разделе «Тесты и ДЗ». Даётся одна окончательная попытка: после отправки ответы сохраняются без возможности изменения, в том числе при ошибке. Для одной палочки нужно ответить правильно на все вопросы. Повторные и одновременные отправки не начисляют дополнительный прогресс. Блокировка ответов проверяется сервером и базой данных. Правильные ответы хранятся на сервере и не передаются ученику. Родители и педагоги без дополнительной роли доступа к тестам не имеют.

Палочки общие для всех видов работы: один успешно пройденный тест, одно принятое ДЗ или одно завершённое занятие с отметкой «Присутствовал»/«Опоздал» дают по одной палочке. Неудачные тесты, отсутствие и отменённые занятия палочек не дают. Общий счётчик вычисляется из уникальных выполненных работ и посещений, поэтому обновление страницы не увеличивает прогресс. Шкала показывает отдельные палочки вместо процентной заливки.

API: `GET /api/v1/homework-tests`, `GET /api/v1/homework-tests/students`, `POST /api/v1/homework-tests`, `POST /api/v1/homework-tests/{id}/submit`. В последнем маршруте используется ID выданного задания из списка, а не ID шаблона теста. Список выдаётся страницами по 20 заданий, параметр `page`.

В административном кабинете и кабинете руководителя вместо редактора тестов показывается «Рейтинг учеников»: активные ученики, места по общему числу палочек, посещённые занятия, принятые ДЗ, работы на проверке, успешные и неудачные тесты и последняя учебная активность. При равном количестве палочек место одинаковое; поиск сохраняет место в общем рейтинге. API рейтинга: `GET /api/v1/learning/rating?search=...&page=1`, только для администратора и руководителя.
