# M4-03 — историческая реализация MFA

26 октября 2026 года MFA удалена из приложения по решению владельца. Администратор входит по email и паролю, сессия действует 12 часов. Экран второго фактора, резервные коды, маршруты `/auth/mfa/*` и команда `mfa-reset` удалены. Переменная `MFA_ENCRYPTION_KEY` больше не читается и не требуется.

Миграция `023_admin_mfa.sql` остаётся неизменной для совместимости уже развёрнутых баз. Сохранённые данные прежнего MFA не участвуют в авторизации; исторические записи Audit Log остаются доступными. Обновление не меняет пароли, роли и блокировки аккаунтов.

Текущие правила входа: [руководство пользователя](site-user-guide.md#1-вход-и-навигация).

Проверка удаления: `backend/internal/app/admin_password_auth_integration_test.go` покрывает вход администратора без ключа, ранее подключённый фактор, срок сессии, служебные операции, отказ другим ролям, восстановление пароля и недоступность старых маршрутов. `frontend/tests/admin-password-login.spec.ts` проверяет вход и повторное открытие аккаунта на desktop и mobile-360. Полный `go test -count=1 ./...` с отдельным PostgreSQL, `go vet ./...`, `go build ./...` и сборка frontend прошли 26 октября 2026 года. Проверка резервирования с отдельной переменной `R12_TEST_DATABASE_URL` в этот прогон не входила.
