# Раздел 12 — frontend

Проверено 2 ноября 2026 года. Дополнены существующие экраны React и интеграция с существующими API.

## Экраны и состояния

| Экран | Где открыть | Состояния и результат |
| --- | --- | --- |
| Принятие приглашения | `#/invitation?token=…` | Проверка ссылки, отсутствие токена, ошибка и повтор проверки, существующий/новый аккаунт, подтверждение принятия. |
| Восстановление и новый пароль | `#/forgot-password`, `#/reset-password?token=…` | Пустая форма, отправка, ошибка и повтор отправки, отсутствующая/недействительная ссылка, подтверждение. Ошибка несовпадения паролей связана с полем и переводит фокус в него. |
| Главная ученика и задание | `#/family`, роль ученика | Загрузка, пустые учебные блоки, ошибка и обновление. Текст, ссылка и файл, история попыток, подтверждение отправки. Фокус при открытии задания и возврате к обучению. |
| Главная родителя | `#/family`, роль родителя | Поиск и переключение детей, загрузка, отсутствие доступных детей/записей, ошибка и обновление. Старые ответы не подменяют выбранного ребёнка. |
| Опубликованные отчёты | Раздел «Отчёты» в кабинете; блок главной родителя | Список и отдельное окно просмотра. При открытии выполняется новый запрос `/family/reports/{id}`. Загрузка, пустой список, ошибки и повтор. Escape закрывает окно; Tab остаётся внутри; фокус возвращается на кнопку открытия. |
| Подготовка и проверка отчёта | `#/family-reports`, управление семьёй в карточке ученика | Черновик, проверка, утверждение, публикация и отзыв; пустая очередь; загрузка/ошибка/обновление. Форма блокируется во время сохранения, сохраняет ввод при ошибке. Подтверждения сохранения и переходов состояния. |
| Обращения и переписка | `#/my-requests`, `#/family-requests` | Пустой список и история, загрузка, ошибки/повторы. Отдельные состояния выбора ребёнка. Подтверждения создания, отправки сообщения и изменения статуса. |
| Центр уведомлений | `#/notifications` | Загрузка, пустой список, фильтр, ошибка/обновление; подтверждение прочтения. При временной ошибке отметки доступна повторная попытка; отказ в доступе очищает данные. |
| События и регистрация | `#/events`, `#/events/{id}` | Список, карточка, создание, регистрация и отмена. Пустые списки, загрузка, ошибки/повторы, подтверждения создания и изменения участия. У документов есть загрузка, пустое состояние, повтор и подтверждение сохранения. |
| Административный список участников | Блок «Участники события» в карточке события; `#/users` для учётных записей | Список заявок и пагинация, доступные сервером действия, подтверждение участия. Отдельная обработка ошибки поиска кандидатов. Учётные записи: загрузка, пустой список, повтор и подтверждения изменений. |

У экранов просмотра без операции записи подтверждение сохранения не требуется. Повтор записи выполняется той же кнопкой после исправления ошибки; загрузка данных повторяется кнопкой обновления или повтора.

После входа родитель и ученик сразу переходят в семейный/учебный кабинет. Подтверждения создания события и обращения передаются в открывшуюся карточку однократно через состояние истории браузера.

## Проверки

- `npm run build` — успешно, включая TypeScript.
- Итоговый прогон 12 файлов Playwright: **82/82 успешно**, по 41 проверке для desktop **1440 × 1000** и mobile **360 × 800**.
- Дополнительно `tests/ui.spec.ts`: **24/24 успешно** в отдельном прогоне — формы, диалоги, навигация, мобильное меню и административные страницы.
- Axe: WCAG 2 A/AA и применимые проверки WCAG 2.1 AA, включая подписи полей и контраст.
- Клавиатура: вход и повтор запроса через Enter, Tab в диалоге, Escape, возврат фокуса, переход к содержимому и фокус ошибки подтверждения пароля.
- Размеры: отсутствие горизонтального переполнения страницы; отдельно проверена внутренняя ширина окна отчёта с длинным именем вложения. Перенос имени исправлен после просмотра скриншота.
- Сохранность ввода при ошибке, блокировка полей во время сохранения, отмена устаревших запросов и очистка данных при отзыве доступа проверены сценариями.

Тесты используют контролируемые ответы API. Это проверка frontend, а не повторная интеграционная проверка PostgreSQL, SMTP или доставки писем. В этом окружении использован установленный Chrome через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`; браузер Playwright отсутствовал. Разовый сбой первого запуска Chrome устранён повторным запуском; итоговые 82 теста прошли без повторов.

Vite сообщает предупреждение о размере основного JS-файла более 500 кБ; сборка завершается успешно.

## Повторить локально

Из каталога `frontend`, Node 22.12+:

```powershell
$env:PATH = "$PWD/node_modules/node/bin;$env:PATH"
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
npm run build
npm run test:ui -- tests/frontend-requirements.spec.ts tests/invitations.spec.ts tests/password-reset.spec.ts tests/student-portal.spec.ts tests/parent-portal.spec.ts tests/family-access.spec.ts tests/family-report-composition.spec.ts tests/family-report-workflow.spec.ts tests/family-requests.spec.ts tests/notifications.spec.ts tests/events.spec.ts tests/event-participation.spec.ts
```

Новые сценарии состояний и фокуса: [frontend-requirements.spec.ts](../frontend/tests/frontend-requirements.spec.ts). Существующие сценарии дополнены проверками подтверждений и возврата фокуса.
