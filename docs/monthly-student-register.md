# Таблица учеников по месяцам

Под списком учеников администратор и руководитель видят таблицу с выбором месяца и выгрузкой в Excel `.xlsx`. В текущем месяце показывается состав на сегодня, в прошлых — на конец месяца по московскому времени. Новая карточка активного ученика автоматически входит в состав; перевод в архив убирает её из текущего состава. Восстановление возвращает ученика без дубликата. Отчисление из отдельной группы меняет группу в таблице; для исключения ученика из общего состава используется архивирование карточки.

После создания или изменения карточки таблица обновляется сразу. При возвращении во вкладку она также загружается заново. История статусов хранится отдельно от списка; при установке обновления для существующих карточек используются сохранённые события архивирования и восстановления. Для месяцев без сохранённых сведений о смене статуса точность ограничена имеющимися данными. ФИО учеников и кураторов отображаются по текущим карточкам; названия групп — по зачислениям на выбранную дату.

В Excel выгружается весь состав за выбранный месяц независимо от страницы и фильтров верхнего списка. Ячейки содержат текст, включая имена, начинающиеся со знака `=`. Файл формируется по актуальным данным при скачивании; ранее скачанные локальные файлы автоматически не изменяются.

API: `GET /api/v1/students/monthly-register?month=2026-11&page=1`, по 20 строк. Для полного Excel добавляется `format=xlsx`. Доступ только администратору и руководителю; будущие месяцы недоступны.
