# v0.1.0 — черновик описания выпуска

**Не опубликован. Tag не создан.** Дата публикации и итоговый commit SHA будут
указаны после выполнения [условий R14](handover-r14.md). Версия 0.1.0 в package.json
не является свидетельством оформленного GitHub Release.

Первый выпуск AIQ Core включает управление пользователями четырёх ролей,
педагогами, учениками и родителями, программами, группами, зачислениями,
занятиями и посещаемостью. Student 360, Dashboard, задачи и audit используют
серверные права; исторический состав и снимки занятий сохраняются. Схема
содержит миграции 001–016. Добавлены ежедневные проверяемые копии с хранением
семи успешных архивов и восстановление в новую БД.

Для установки: [README](../README.md). Перед обновлением сделать копию и
следовать [миграциям](operations.md#миграции-и-обновление): старая версия до
разделения участников/отметок несовместима со схемой 016. Автоматических down
миграций нет; возврат выполняется восстановлением в отдельную БД с совместимым
приложением. Рабочую БД пробным восстановлением не перезаписывают.

К выпуску прикладываются исходники, `MANIFEST.json`, SHA-256 архива,
[отчёты испытаний](r13-validation-report.md), отчёты копирования/восстановления
и принятый [чек-лист](acceptance-r14.md). Текущие открытые условия A01–A09
не являются согласованными ограничениями выпущенной версии. Перед публикацией
этот раздел заменяется фактическими решениями, ссылками на CI и проверенный SHA.

Готовность к работе с реальными персональными данными подтверждается отдельно.
