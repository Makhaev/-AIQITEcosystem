# Группы и зачисления

Группа содержит название (1–200 символов), программу, необязательного основного педагога, положительную целочисленную вместимость и статус `draft`, `active` или `archived`. Создание по умолчанию создаёт черновик. Новая программа должна быть активной, новый педагог — не архивным. Существующие связи с архивными справочниками сохраняются. Программу можно менять только пока у группы нет зачислений и занятий.

Администратор создаёт, изменяет и архивирует группы, зачисляет, выводит и переводит учеников. Руководитель читает все группы. Педагог читает группы, в которых он основной педагог или педагог занятия; состав содержит только имена учеников и данные зачислений, без родительских контактов. Куратор читает группы закреплённых учеников, включая исторические зачисления; в составе видит только своих учеников. Сочетание ролей расширяет доступ только при наличии соответствующей связи. Сессия и права повторно проверяются внутри транзакции; изменения требуют CSRF.

## API

Префикс `/api/v1`.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/groups` | Поиск по названию без учёта регистра, статус, `page`, `page_size` |
| POST | `/groups` | Создание: `name`, `program_id`, `teacher_id`, `capacity`, `status` |
| GET | `/groups/{id}` | Поля группы, названия программы и педагога, `active_count`, история `enrollments` |
| PATCH | `/groups/{id}` | Изменение полей; `status: archived` архивирует, `status: active` восстанавливает |
| POST | `/groups/{id}/enrollments` | Зачисление: `student_id`, `starts_on` |
| PATCH | `/groups/{id}/enrollments/{enrollment_id}` | Вывод: `ends_on` |
| POST | `/groups/{id}/enrollments/{enrollment_id}/transfer` | Перевод: `target_group_id`, `transfers_on` |

Даты — календарные `YYYY-MM-DD`. Окончание не может быть раньше начала. При переводе дата окончания старого и начала нового зачисления равна `transfers_on`. Ответ перевода: `{previous, enrollment}`. При повторном поступлении создаётся новый ID. Физического удаления групп и зачислений через API нет.

Активное зачисление — запись с `ends_on = null`. Оно сразу занимает место, в том числе при будущей дате начала. Указание `ends_on` завершает запись и сразу освобождает место; автоматического завершения по календарю нет. Новые зачисления разрешены только для активного ученика в активную группу. Архивирование группы сохраняет состав и историю; существующих учеников можно вывести или перевести из архива.

## Целостность и параллельные операции

- Частичный уникальный индекс запрещает два активных зачисления одного ученика в одну группу.
- Триггер зачисления блокирует и обновляет строку группы до подсчёта мест. Параллельные INSERT и уменьшение вместимости сериализуются на той же строке. Устаревший снимок `REPEATABLE READ` получает ошибку сериализации вместо переполнения.
- Уменьшение вместимости ниже количества активных зачислений запрещено. HTTP возвращает `409 group_full`.
- Перевод блокирует две группы в порядке ID, закрывает источник, создаёт новое зачисление и сохраняет аудит в одной транзакции. Заполненная, неактивная или отсутствующая целевая группа, повторное зачисление либо ошибка даты откатывают все изменения.
- Закрытые зачисления нельзя удалить, переоткрыть или перенести изменением внешнего ключа. Их исходные идентификаторы и даты начала неизменны.
- Таблица `lesson_participants` сохраняет исходные занятие, группу, ученика и зачисление; составные FK запрещают чужую группу. Отметка в `attendance` связана PK/FK с тем же ID участника. Перевод и архивирование сохраняют эту историю. [Расписание и сохранённый журнал](lessons-and-journals.md) предоставляют API создания занятий, снимка состава и его явной корректировки администратором. Разделение таблиц с сохранением данных выполняет миграция 016.

Интерфейс: список и редактирование групп, фильтры, архивирование, заполнение группы и карточка истории; формы зачисления, вывода и перевода. Списки выбора загружаются по всем страницам API, ранее выбранные архивные справочники доступны при редактировании.
