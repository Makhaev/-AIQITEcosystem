## Контроль перед подписью

- [ ] Для каждого R01–R14 приложены PR/commit, результат и доказательство;
  отклонения имеют явное решение заказчика.
- [ ] Репозиторий приватный, имя/remote соответствуют решению владельца;
  заказчик вошёл и подтвердил доступ к исходникам/настройкам.
- [ ] Исходники, миграции, тесты, Compose/Dockerfile, env-шаблоны, OpenAPI,
  схема, роли, README и инструкции получены; архив и manifest проверены.
- [ ] CI успешен на окончательном SHA, нет воспроизводимых ошибок доступа
  или основных операций; сквозной сценарий прошёл на чистой БД.
- [ ] Нагрузочный отчёт относится к этому SHA и согласованному стенду;
  по endpoint выполнены p95, нет неожиданных ошибок и повреждения данных.
- [ ] Стенд доступен заказчику, HTTPS и миграции проверены; адрес записан ниже.
- [ ] Ежедневная служба, защищённое хранилище, семь копий, отказ и
  восстановление в новую БД подтверждены оператором.
- [ ] Все замечания устранены либо допустимость явно согласована.
- [ ] Публикация кода, изменение GitHub-доступа, развёртывание и выпуск
  разрешены отдельными решениями в соответствующем объёме.
